# Электронная приёмная GBA

Статическая страница-форма для Minecraft RP-сервера. Один файл `index.html` — HTML, CSS и JS внутри, сборка не нужна.

## Запуск

1. Откройте `index.html` и впишите свой Discord webhook в константу `DISCORD_WEBHOOK_URL` вверху блока `<script>`.
2. Залейте файл в репозиторий на GitHub.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

Шрифт Inter подключается с Google Fonts. Если страница откроется без интернета, подставится системный шрифт — вёрстка не поедет.

Тёмная тема включается сама по системной настройке устройства, отдельного переключателя нет.

## Как править

Всё настраиваемое — вверху `<script>`:

- `OFFICES` — список офисов. Чтобы добавить новый, допишите строку вида `{ name: "Nordvik", letter: "N", key: "nordvik" }`. `letter` — буква талона, `key` — уникальный ключ счётчика.
- `REASONS` — список причин обращения.
- `COUNTER_NAMESPACE` — пространство имён счётчика талонов.
- `TICKET_DIGITS` — сколько цифр в номере (3 → `G-047`).

## Номера талонов

Счётчик берётся по цепочке бесплатных внешних сервисов: `abacus.jasoncameron.dev` → `api.counterapi.dev` → `api.countapi.xyz`. Первый ответивший даёт номер. Если не ответил никто, номер присваивается по времени подачи (ЧЧММ), и на странице показывается предупреждение.

Счётчик считает талоны отдельно по каждому офису — у Goxten и Bernlend своя нумерация.

## Что стоит знать

Webhook URL лежит в открытом JS и виден любому, кто откроет исходник страницы. Это неизбежно без бэкенда. Если канал начнут спамить — удалите webhook в настройках Discord-канала и создайте новый; старая ссылка сразу перестанет работать.

История заявок на сайте не хранится — только в Discord.
