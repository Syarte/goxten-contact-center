# Электронная приёмная Göxten Contact Centre

Статическая страница-форма для Minecraft RP-сервера. Вся логика в `index.html` — HTML, CSS и JS внутри, сборка не нужна. Рядом лежат `logo.png` (знак для шапки, с прозрачным фоном) и `logo-full.png` (полный логотип со словесной частью, на сайте не используется — про запас).

## Запуск

1. Залейте файлы в репозиторий на GitHub. `logo.png` должен лежать рядом с `index.html`, иначе в шапке будет пустое место.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

Шрифт Inter подключается с Google Fonts. Если страница откроется без интернета, подставится системный шрифт — вёрстка не поедет.

Тёмная тема включается сама по системной настройке устройства, отдельного переключателя нет.

Discord webhook уже вписан в константу `DISCORD_WEBHOOK_URL` вверху блока `<script>` — менять ничего не нужно.

## Как править

Всё настраиваемое — вверху `<script>`:

- `OFFICES` — список офисов. Сейчас один: `{ name: "Börnlend" }`. Если офис один, он подставляется в форму сразу; допишете второй — появится выбор.
- `REASONS` — причины обращения вместе с литерами талонов: `{ name: "Медицина", letter: "D" }`. Литера определяет номер талона, у каждой причины своя нумерация. Новая причина — новая строка со свободной буквой.
- `COUNTER_NAMESPACE` — пространство имён счётчика талонов.
- `TICKET_DIGITS` — сколько цифр в номере (3 → `A-047`).
- `MAX_FILES` и `MAX_TOTAL_MB` — ограничения на приложенные документы.

## Номера талонов

Литера талона берётся из причины обращения: гражданство — A, домовое имущество — B, образование — C, медицина — D, регистрация государства — G. Нумерация у каждой литеры своя, то есть A-001 и D-001 существуют одновременно.

Счётчик берётся по цепочке бесплатных внешних сервисов: `abacus.jasoncameron.dev` → `api.counterapi.dev` → `api.countapi.xyz`. Первый ответивший даёт номер. Если не ответил никто, номер присваивается по времени подачи (ЧЧММ), и на странице показывается предупреждение.

## Документы

К обращению можно приложить файлы — перетаскиванием или через выбор. Они уходят вложениями к тому же сообщению в Discord, отдельного хранилища нет.

Ограничение по умолчанию: 5 файлов и 8 МБ суммарно. Восемь мегабайт — это лимит Discord на вложения для сервера без бустов; если у сервера есть бусты, лимит выше и `MAX_TOTAL_MB` можно поднять. Слишком большой файл форма не примет и скажет об этом до отправки.

## Что стоит знать

Webhook URL лежит в открытом JS и виден любому, кто откроет исходник страницы. Это неизбежно без бэкенда. Если канал начнут спамить — удалите webhook в настройках Discord-канала и создайте новый; старая ссылка сразу перестанет работать.

История заявок на сайте не хранится — только в Discord.
